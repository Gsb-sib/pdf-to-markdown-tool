# 2026-11-12 速度、公式与输出整理

本轮针对三个反馈修改：每份文档重复加载模型、识别有误、公式裁剪图过多。公式功能仍为实验功能，不能保证任意教材达到 99%。

## 改动

- 模型进程跨文档复用；服务停止时销毁。异常、超时会销毁失效进程，下次任务重新启动。公式任务仍串行，忙碌返回 429。
- 同一 L 模型启用 CPU oneDNN、4 个公式一批的推理，不通过换成小模型提速。
- 在内存中按页面 PNG 的 SHA-256 缓存最近 32 页的区域与 LaTeX。重复页跳过模型推理；图片不保存在缓存中，重启清空。
- `exportFormulaImages` 默认 `false`。网页有独立勾选框；普通插图仍按原逻辑提取。仅开启公式增强后此选项才有效。
- 公式增强时，文字层中字形位置和字号明确的简单上下标尝试按几何位置恢复。仅处理简单字母、数字和少量符号，不猜测复杂分式。普通文字模式保留原行为。
- 行内公式与紧邻正文补空格；检测框混入正文的保护及待复核标记继续保留。

## 实际 HTTP 结果

Windows x64、Intel Core Ultra 9 185H、约 32 GB 内存；CPU 4 线程，模型权重已在本机缓存，使用同一套固定公式 PDF。以下为完整请求墙钟时间，未计安装和首次权重下载。

| 请求 | 区域数 | 耗时 | 导出公式 PNG | ZIP 大小 |
| --- | --- | --- | --- | --- |
| 6 式文字页，首次初始化 | 6 | 45.735 秒 | 0 | 372 字节 |
| 同页重复上传，内存缓存命中 | 6 | 0.140 秒 | 0 | 372 字节 |
| 另一份 8 式文字页，模型已加载 | 8 | 48.578 秒 | 0 | 389 字节 |
| 6 式页，缓存命中并开启原图 | 6 | 0.219 秒 | 6 | 35,236 字节 |

**缓存命中耗时不能推广到新页面。** 新页面仍需检测与公式识别；不能用 MB 数推算时间。旧版本 75–273 秒是历史测量，不是严格控制变量的同轮性能比较，不据此报告稳定加速比例。

教材单页仍需约四分钟，说明当前 CPU 优化没有彻底解决公式密集文档的速度问题。21 份文字及扫描件 HTTP 回归保持原结果：忽略空白字符一致率 99.740327%，保留词间空白为 98.771211%；这是文字指标，不能解释为公式准确率。

最终运行包另一次 HTTP 复核（含 Markdown/ZIP 下载校验）：普通文字示例 0.931 秒，保留 1 张原插图；6 式页首次 64.465 秒，重复页 0.214 秒，均不导出公式图片。首次耗时存在波动，不能把较快的一次当作固定速度承诺。

核验了 JSON、下载 Markdown 和 ZIP 内 Markdown 一致、ZIP CRC、原图开关与文件数量。6 式与 8 式输出逐式按原固定答案复核数学结构，涉及分式、上下标、积分/求和上下限、导数与根式。这 14 个公式来自既有合成样本，不是新的独立准确率样本；输出成功不能代替数学结构复核。

另复测 8 式扫描页，服务端转换耗时 66.972 秒，导出图片 0 张；逐式对照同一参考答案，分式、上下标与求和/积分结构保留。扫描页与文字页对应相同公式，不增加独立公式样本数。47 项 Java 自动测试通过，失败与错误为 0。公式检测框稍微覆盖相邻文字时，公式与正文仍补分隔空格；Windows 停止脚本会同时结束模型子进程。

## 准确性与边界

真实教材中的漏检上下标已通过原响应重放检查：原线性 `Fₙ`、`Fₙ₋₁` 一类字形可恢复为 `$F_{n}$`、`$F_{n-1}$`，但无法从错误的 Unicode 映射推断原字体的数学语义。重放只验证集成逻辑，不等于新的模型准确率测量。

检测框混入正文的区域仍保留原文与 `FORMULA_REVIEW_REQUIRED` 标记，不用模型的错误输出覆盖正文。扫描公式、复杂多栏、字体映射和未检测出的复杂公式仍需对照原 PDF。旧的 99.74% 指标只代表固定文字样本忽略空白的字符一致率，不能表示公式准确率。

模型常驻会持续占用内存，用完后停止服务以释放。新设置只影响新任务，旧任务中的图片和下载文件不会自动删除。

## 复现

```powershell
mvn package
# 按根 README 配置环境并启动服务后：
py benchmarks/verify_formula_downloads.py benchmarks/data/math-layout.pdf
py benchmarks/verify_formula_downloads.py benchmarks/data/math-layout.pdf --export-formula-images
```

脚本检查输出文件、开关和一致性，不能自动判定公式语义。
